# Ola_Ride_Booking_Project
## Project Overview

This project analyzes 1,00,000+OLA ride bookings using SQL and visulizes insights through an interactive Power BI darshboard.
The goal is to understand booking patterns, customer behavior, cancellation,revenue contribution and driver-customer performance metrics.

--Tech Stack--
